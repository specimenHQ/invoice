INVOICE AI Prompt Generator

This version is Ollama-only. It runs through your local model.

Use START_STORYBOARD_GENERATOR.bat to open the generator through the local server:

http://127.0.0.1:8777

Setup:

1. Install and start Ollama.
2. Install the model named in .env, for example:
   ollama pull qwen3:8b
3. Run START_STORYBOARD_GENERATOR.bat.

The storyboard controls save per panel in the browser and are included in the prompt, AI metadata, and JSON export.
