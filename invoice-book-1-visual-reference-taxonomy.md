# INVOICE - BOOK 1

Visual reference taxonomy

## Purpose

These references are not all for the same moment.

Book 1 should use the abstract grid references early and save explicit crate/cube/warehouse imagery for later books or later reveals. The prompt machine must distinguish between:

1. Grid as structure
2. Cube as geometry
3. Crate as material
4. Warehouse/crate multitude as future/later imagery

## Book 1: Useful Now

Use these qualities for Pages 15-18, the slow-growing grid:

1. The building facade perspective: grid receding into black, vertical pull, pressure toward a vanishing point.
2. The reflective window grid: flat surface, repeated lines, one panel opening, grid as a skin.
3. The isometric tile reference: grid as implied 3D space, missing cells, incomplete system.
4. The impossible tiled loop: grid bending around impossible geometry, dimensional confusion.
5. The grow-tent structure only as abstract silhouette logic: dark box, framed edges, enclosure, interior growth. Do not use its colors or product look.

Prompt language for this phase:

Black-on-black abstract grid, barely visible right angles, one line crossed by another, incomplete cells, displaced planes, grid receding into darkness, grid as pressure, no literal cubes, no crates, no warehouse, no full room.

## Book 1: Use Later In The Book

Use these qualities after the grid has earned material:

1. Wood grain and crate-like texture.
2. A seam or opening panel.
3. A single container becoming readable.
4. Dark enclosure that implies family-home pressure without literal furniture.

The cardboard box reference can inform the emotional plainness of the first crate, but avoid comedy, text labels, office setting, or modern packaging details.

## Book 2 And Later

Save these references for the explicit crate/warehouse/memory-system arc:

1. Rows of open crates.
2. Shelves packed with boxes.
3. Modular crates that fit together.
4. Cubes with glowing maze-like markings.
5. Crate wood becoming building material.
6. The sense that each container may hold something different.

These should not appear literally in Book 1 before the narrator reaches the door.

## Final-Page / Future Silhouette Reference

The figure surrounded by many circular marks is useful only as a distant future language or final-page silhouette reference.

For Book 1, the silhouette can appear on Page 52, but not surrounded by fully readable memory-forms. The circle/egg/memory field belongs later.

## Generator Warning

For Pages 15-18, do not ask for "many cubes." Ask for "a grid beginning to grow."

Good:

Black-on-black grid emergence, faint right-angle intersections, incomplete cells, vertical and diagonal pressure, perspective lines barely visible in darkness.

Bad:

Rows of cubes, warehouse crates, stacked boxes, shelves, explicit containers.
